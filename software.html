NewCandy

NewCandy is an updated version of the Chemistry ANd DYnamics (CANDY) model outlined in Van Clepper et al. 2022. NewCandy simultaneously solves chemistry, dynamics, and pebble growth for a 1D vertical column in a protoplanetary disk. Molecular abundances for each grid cell are solved using Astrochem chemical solver (Maret & Bergin 2015). Molecular species and dust grains are allowed to diffuse between adjacent cells. Additionally, small dust grains, which are active in chemistry, grow to larger pebbles, sequestering ice away from the active chemistry of the disk. If you would like to use NewCandy in your research, documentation and installation instructions can be found on my github page.

ParTrace

ParTrace is a particle tracking algorithm to trace the trajectories of tracer particles in 3D. The first results of this new work are outlined in Van Clepper et al. 2025, where we show that 3D Meridional flows around an embedded planet can drive the mixing of small grains across the gap opened in the protoplanetary disk. ParTrace can be modified to track tracer particles through any 3D hydrodynamic mesh where gas density and velocity are defined. If you would like to learn more about ParTrace, check out the github repo or get in touch!
